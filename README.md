## ✦ Download & Run

**Step 1** .... Download the archive

```
Download base-wallet-intel-v3.zip from the repo
```

**Step 2** .... Extract the archive

```bash
# Extract zip to a folder
unzip base-wallet-intel-v3.zip -d base-wallet-intel
cd base-wallet-intel
```

**Step 3** .... Run

```bash
# Open index.html in a browser, or follow the instructions inside the archive
start index.html
```
